# Информатика 3–11

## Простыми словами

Это сайт школьного курса информатики: уроки для 3–11 классов, материалы к ЕГЭ, презентации и игры «Собери код» — всё в одном месте, без установки и регистрации.

Сделан на HTML и CSS, материалы разложены по классам; небольшой сервер на Python отдаёт страницы локально, если открывать курс не из интернета.
