Цель урока

Познакомить с базовыми конструкциями языка Python (вывод, переменные, условия, циклы) и научить читать и предсказывать работу простых программ.

Планируемые результаты

Предметные: знать синтаксис print, переменных, if и while; уметь объяснять результат программы. Метапредметные: строить логические рассуждения, выполнять трассировку. Личностные: настойчивость в поиске решения, аккуратность в коде.

Оборудование и материалы

Компьютер, проектор, презентация урока, лекция (для учителя), интерактивное приложение «Трассировка», среда Python (обзорно), тетрадь.
