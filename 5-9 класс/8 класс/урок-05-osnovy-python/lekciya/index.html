Основы программирования на Python

8 класс · Раздел «Основы алгоритмизации и программирования»

1. Организация урока

Цель урока: познакомить с базовыми конструкциями языка Python и научить читать и предсказывать работу простых программ.

Задачи:

  • сформировать понятия «переменная», «ветвление», «цикл»;
  • научить выполнять простые программы «вручную» (трассировка);
  • закрепить понимание трёх базовых конструкций алгоритма.

2. Вводная часть

Спросите: «Может ли компьютер сам придумать программу?». Нет — программу пишет человек, а компьютер только её выполняет. Программа — это алгоритм, записанный на понятном компьютеру языке.

3. Основной материал

3.1. Вывод и вычисления

Команда print выводит значения на экран. Python соблюдает обычные правила арифметики.

print("Привет, мир!")
print(2 + 3 * 4)
Привет, мир!
14

3.2. Переменные

Переменная — именованное хранилище значения. Оператор = записывает значение; справа — выражение, которое вычисляется.

age = 12
age = age + 1   # теперь age == 13
print(age)
13
Термин: переменная — именованная область памяти, в которой хранится значение; значение может меняться в ходе выполнения программы.

3.3. Ветвление (if / else)

Условная команда даёт программе выбрать один из путей в зависимости от логического условия.

score = 85
if score >= 60:
    print("Зачёт")
else:
    print("Не зачёт")
Зачёт

Обратите внимание на отступы: блок под if и else выделяется 4 пробелами. Операторы сравнения: >=, <=, ==, !=, >, <.

3.4. Цикл while

Цикл повторяет блок, пока условие истинно. Ключевое требование — переменная в условии должна меняться, иначе цикл не завершится.

n = 1
while n <= 3:
    print(n)
    n = n + 1
1
2
3
Важно. Без строки n = n + 1 цикл был бы бесконечным. Выполняя цикл вручную, записывайте, как меняется n на каждом шаге.

4. Три базовые конструкции

  • Последовательность — команды выполняются по порядку;
  • Ветвление — выбор пути по условию;
  • Повторение — цикл.

Из них собирается любая программа, какой бы сложной она ни была.

5. Практическая часть

Ученики в приложении «прокручивают» выполнение кода по шагам и выбирают, что выведет программа. Это развивает навык трассировки (выполнения кода вручную), важный для ОГЭ/ЕГЭ.
