О чём урок

Программирование — это составление алгоритма на понятном компьютеру языке. Сегодня возьмём самый популярный школьный язык — Python.

Рассмотрим: вывод на экран, переменные, условия «если», циклы «пока».

Условия

Команда «если»

score = 85
if score >= 60:
    print("Зачёт")
else:
    print("Не зачёт")
Зачёт

Циклы

Повторение команд

n = 1
while n <= 3:
    print(n)
    n = n + 1
1
2
3

Цикл «пока» повторяет блок, пока условие истинно. Важно, чтобы цикл когда-нибудь завершился.

Итог по конструкциям

Три главные конструкции

  • Последовательность — команды по порядку.
  • Ветвление — выбор пути по условию (if).
  • Повторение — цикл (while).

Из этих блоков строятся любые программы.
