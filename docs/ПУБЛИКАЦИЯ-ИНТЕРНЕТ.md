# Как опубликовать сайт курса «Информатика 3–11 + ЕГЭ» в интернете

Сайт уже собран в папку **`D:\informatika-site`** (копия всех уроков, лекций,
приложений, методических карт, главная `index.html`, подписка). Это **статический сайт** —
ему не нужен сервер-обработчик, его достаточно «положить» на любой хостинг.

---

## Вариант A. Раньше всего — бесплатный хостинг (GitHub Pages)

Быстро и бесплатно, без покупки домена.

1. Создать аккаунт на **github.com**, завести публичный репозиторий, например `informatika-course`.
2. Загрузить **содержимое** `D:\informatika-site` (саму папку `informatika-site` не копируем —
   копируем её содержимое: `index.html`, `1-4 класс/`, `5-9 класс/`, `10-11 класс/`, `docs/`, …).
   Можно через веб-интерфейс (Drag & Drop) или `git push`.
3. GitHub → **Settings → Pages** → Source: **main branch / root** → Save.
4. Через 1–2 минуты сайт откроется по адресу
   `https://<ваш-логин>.github.io/informatika-course/`
5. (Опционально) Подключить свой домен в **Settings → Pages → Custom domain**.

> Важно: GitHub Pages обслуживает только **публичные** репозитории — весь курс станет виден
> всем. Если этого не хотите — используйте вариант B (платный хостинг) или оставьте локально.

## Вариант B. Платный хостинг + свой домен

1. Купить домен у регистратора (Reg.ru, Timeweb, REG.RU и т.п.), например `informatika-kurs.ru`.
2. Выбрать хостинг со статикой или VPS (Timeweb, Beget, Reg.ru, RU-CENTER).
3. Загрузить **содержимое** `D:\informatika-site` в каталог `public_html/` (или `www/`) хостинга
   через Файловый менеджер панели или FTP (FileZilla).
4. Привязать домен: в панели хостинга «Добавить сайт» → указать купленный домен.
5. Прописать DNS (обычно автоматически/по инструкции хостинга).
6. Дождаться обновления DNS (от нескольких минут до 48 ч) — сайт заработает по домену.

## Вариант C. Локально на своём компьютере (без интернета)

См. `docs/ЛОКАЛЬНЫЙ-СЕРВЕР.md` — как открыть сайт http://localhost прямо с диска D:.

## После публикации (обязательно)

1. **Домен/канонические ссылки.** В коде сайта прописан плейсхолдер `https://YOUR-DOMAIN.ru/`
   (canonical). После публикации замените его на фактический адрес (в `_tools/_design.py`/
   `render_lessons.py`) и пересоберите, либо массовой заменой по всем HTML.
2. **Проверьте доступ к подписке.** Страницы уроков закрыты оверлеем по ключу `DF7US-RYBAA-C3VP2`.
3. **SEO.** Теги (meta description, keywords, robots, Open Graph) — уже на страницах.
   Для России стоит подать сайт в Яндекс.Вебмастер (webmaster.yandex.ru) и Google Search Console
   и добавить sitemap.xml (при желании сгенерируем).
