# Проверка оплат курса «Информатика 3–11 + ЕГЭ» по почте

Автор: Панасюк Кристина Эрнстовна · почта для чеков: k.panasyuk@bk.ru · Telegram @kristinapnsk
Подписка: 399 ₽/мес · банковский перевод на Сбербанк.

Этот документ — процедура **ручной/полуавтоматической проверки** подтверждений оплаты,
которые клиенты присылают на почту, перед выдачей ключа активации.

---

## 1. Виды принимаемых чеков (что искать в письмах)

Перевод совершается банковским переводом (Сбер). Подтверждением служит **любой из**:

| # | Вид подтверждения | Что должно быть видно |
|---|---|---|
| 1 | **Скриншот СберБанк Онлайн** (вкладка «Платежи/История», детали перевода) | сумма **399 ₽**, получатель на карту `4081 78…6398`, дата, статус «Исполнен», свои ФИО/номер |
| 2 | **Чек (квитанция) перевода** из приложения банка | код авторизации/номер операции, сумма, дата, комиссия, получатель |
| 3 | **Скриншот SMS/пуша банка** «Перевод выполнен» | сумма, последние цифры карты получателя `…6398`, время |
| 4 | **Выписка по карте/счёту** (фрагмент) | списание 399 ₽, дата, контрагент |
| 5 | **Платёжное поручение** (для юр. лиц/по запросу) | реквизиты получателя, сумма, назначение платежа |
| 6 | **Номер операции переводом** (подтверждение текстом) | номер, дата, сумма — можно сверить с банком |

**Не принимаем как подтверждение**: пустые скриншоты, «я перевёл, проверьте», ссылки на
несуществующие платёжки, скрины без видимой суммы/получателя, чеки других сумм.

## 2. Критерии валидности перевода

Проверить, что оплата **реальная и именно за подписку**, по 4 пунктам:
1. **Сумма** = 399 ₽ (или кратна 399 для продления на N мес).
2. **Получатель** — карта/счёт, оканчивающиеся на `...6398` (Сбер, счёт 40817810938046976398).
3. **Дата** — в пределах сегодня–2 дня (свежий платёж).
4. **Отправитель** — имя/номер в письме совпадает с тем, кому собираемся выдать ключ.

⚠️ Если хотя бы один пункт не читается — запрашиваем уточняющий скрин (шаблон №2).

## 3. Алгоритм проверки (по почте)

1. Зайти в почту → папка **Входящие** (или поиск по `перевод`, `чек`, `квитанция`, `оплата`).
2. Открыть письма с вложениями-скринами или текстом «оплатил/перевёл».
3. Сверить по критериям раздела 2.
4. Если всё ок → выдать ключ (автоответ, шаблон №1).
5. Если нет → запросить доп. подтверждение (шаблон №2).
6. Пометить письмо обработанным (папка/метка), чтобы не выдать дважды.

## 4. Ключ активации

Универсальный ключ курса: **`DF7US-RYBAA-C3VP2`** (один ключ, хранится в localStorage на
устройстве клиента). Выдаётся после успешной проверки оплаты.

> Совет: при массовых продажах можно завести отдельные ключи на клиента (изменять MASTER
> в `_tools/_activation.js` и `_tools/_design.py`), но для старта подойдёт единый.

## 5. Быстрая проверка через инструменты (когда почта подключена)

В MultiTool после подключения Яндекс.Почты (апп-пароль в настройках) будут доступны инструменты:
- `yandex_mail_search` — поиск писем по теме/отправителю/тексту (отфильтровать вложения с чеками);
- `yandex_mail_get_message` — открыть письмо и прочитать текст/проверить вложение;
- `yandex_mail_send` — отправить автоответ с ключом (после подтверждения клиентом).

Это позволяет вести проверку прямо из чата MultiTool.
