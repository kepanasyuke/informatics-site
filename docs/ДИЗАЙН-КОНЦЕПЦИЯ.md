# Единая дизайн-концепция проекта «Информатика 3–11 + ЕГЭ»

Все страницы проекта (главная-лендинг, подписка, презентация, лекция, игра,
методическая карта) объединены одной дизайн-системой. Этот документ описывает
правила, чтобы не гадать: одинаковый «вид и поведение» в любом месте проекта.

Реализация: `_tools/_design.py` (токены CSS, контекстное меню, сетка, JS).
Подключено генераторами `gen_nav.py` (лендинг) и `render_lessons.py` (уроки).

---

## 1. Палитра (из референсов)

Берём акценты плакатного шаблона презентаций и «горячих клавиш»; всё — через
CSS-переменные `--ds-*`.

| токен | значение | где |
|---|---|---|
| `--ds-paper` | `#fffdf6` | светлый фон «бумаги» (все страницы) |
| `--ds-ink` | `#191f33` | основной текст |
| `--ds-mut` | `#5b6b83` | вторичный текст |
| `--ds-ac` | `#e8436f` | **главный акцент (розовый)** |
| `--ds-ac2` | `#6d4fd1` | вторичный акцент (фиолетовый) |
| `--ds-ac3` | `#2563eb` | третий акцент (синий) |
| `--ds-soft` | `#f2eefb` | мягкие подложки/чипы |
| `--ds-line` | `rgba(40,50,80,.12)` | разделители |

Правило: **один главный акцент** (розовый) на страницу; фиолетовый и синий —
только для «вторичных» смыслов (жёлтый — заметки, зелёный — успех, красный — ошибка).

## 2. Единое контекстное меню

У ВСЕХ страниц верхняя тёмная плашка-меню (адаптивная, с бургером на мобильных):

- слева — бренд (название раздела);
- в центре — навигация по якорям/разделам с подсветкой **текущего** пункта (класс `.on`);
- справа — кнопка-CTA «Подписка 399 ₽» + бургер.

**Контекстность** = меню разное в зависимости от типа страницы:

| тип страницы | пункты меню (пример) | активный |
|---|---|---|
| лендинг (`index.html`) | Главная, О курсе, Классы, ЕГЭ, Тарифы, Контакты | контекстный |
| подписка (`podpiska-399.html`) | На главную, Что входит, Тариф, Как оплатить, Контакты | «Подписка» |
| презентация урока | ← Предыдущий урок, Презентация/Лекция/Игра/Карта, следующий → | текущий компонент |
| лекция / игра / карта | те же + навигатор курса | текущий компонент |

## 3. Сетка «до 3 плашек в ряд»

**Главное правило:** карточки («плашки») выкладываются **максимум в 3 колонки**.
Больше 3 в ряд — недопустимо: взгляд теряется, строки становятся тесными.

- карточки-фичи / темы / тарифы — **до 3 в ряд**;
- при 1–2 элементах — они занимают первые колонки, остальное пусто;
- **куда помещать «остальное»** (то, что не влезло в 3 плашки):

| если карточек… | как раскладываем |
|---|---|
| до 3 | одна строка в 3 колонки |
| 4–9 | 3 строки по 3 (для объёмных сеток) ИЛИ вертикальный список |
| больше 3 но они короткие | **вертикальный список** (стек), а не 4-я колонка |
| много однотипных (справочники, таблицы) | **таблица/список** слева направо, не карточки |
| мелкие сущности (классы, шаги) | компактные чипы в одну строку (wrap), не плашки |

Пример: карточки классов 3–11 = **11 штук** → не «11 в ряд», а гибкая сетка
`auto-fill minmax(200px)` (обычно 3–4) — но в рамках концепции разбиваем
на **«Начальная школа (3–4)», «Основная (5–9)», «Старшая (10–11)» + ЕГЭ** —
три смысловые группы, в каждой до 3 карточек.

## 4. Иерархия компонентов

- **Герой/заголовок** — крупный `.ds-title`, один на страницу.
- **Чипы `.ds-chip`** — короткие метки (Презентация / Лекция / Игра / Карта / ЕГЭ).
- **Карточки `.ds-card`** — базовый блок сетки; `.ds-accented` — акцентная (горячий тариф).
- **Заметки**: `.ds-note` (жёлтая), `.ds-ok` (зелёная), `.ds-warn` (красная).

## 5. Типографика

- системный стек `system-ui, Arial` (офлайн, единый на всех страницах);
- цифры/статистика — `font-weight:900`, крупные;
- коды/ключи — моноширинный `ui-monospace, Consolas`;
- не более 1 акцентного цвета в заголовке на экран.

## 6. Куда помещать «остальное» (сводное правило)

1. **3 и меньше тематических понятий** → 3 карточки в ряд.
2. **4–6 ссылок одного типа** → вертикальный компактный список/чипы.
3. **Табличные данные** (горячие клавиши, реквизиты, этапы) → таблица,
   **не** карточки.
4. **Много сущностей** (все уроки) → группировать по смыслу (классы/треки),
   внутри каждой группы ≤3 плашек, остальное — вложенным списком.
5. **Длинный текст** (лекция) → статья одной колонкой (max-width 760–820px),
   без боковых карточек.

## 7. Поведение (единый JS)

- активация подписки через ключ → `localStorage.inf_act` (единый механизм);
- бургер-меню на мобильных `.ds-nav.open`;
- оверлей «Доступ по подписке» — одинаковый во всех типах страниц.
