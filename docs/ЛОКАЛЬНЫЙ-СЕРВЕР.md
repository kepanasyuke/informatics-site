# Запуск сайта локально (сервер) с диска D:

Сайт собран в **`D:\informatika-site`**. Чтобы открыть его как настоящий сайт
(а не как файлы `file://`), запускается локальный веб-сервер. Тогда работают
переходы по страницам, меню и весь JS, который может ограничиваться в режиме `file://`.

## Способ 1 — приложенный скрипт (проще всего)

В корне `D:\informatika-site` есть файл **`server.py`** (создан). Запуск:

1. Убедиться, что установлен **Python 3** (проверка: `python --version` в консоли).
2. Открыть командную строку (PowerShell / cmd) в папке сайта.
3. Выполнить:
   ```
   python server.py
   ```
4. Открыть в браузере: **http://localhost:8000** — откроется `index.html`.

Скрипт поднимает сервер в текущей папке на порту 8000.

## Способ 2 — встроенный модуль Python (без файла)

```
cd /d D:\informatika-site
python -m http.server 8000
```
Открыть http://localhost:8000

## Способ 3 — если Python не установлен

- **Node.js**: `npx serve D:\informatika-site` (устанавливает serve) → http://localhost:3000
- **VS Code**: открыть папку → расширение «Live Server» → «Go Live».
- **Двойной клик** по `index.html` — откроется без сервера (с ограничением `file://`),
  но для локального просмотра большинства страниц достаточно.

```

podpiska-vk.html    — подписка через сервисы VK

5-9 класс/          — уроки 5–9 классов (ИКТ + Программирование)
10-11 класс/        — уроки 10–11 + подготовка к ЕГЭ
docs/               — документация и инструкции

```

## Примечания

- Ключ доступа к платным урокам: `DF7US-RYBAA-C3VP2`.
- Демо-урок (8 кл, «Системы счисления») открывается без ключа.
- Если нужно поставить сервер на другой порт: `python server.py 9000` (если скрипт принимает порт)
  или `python -m http.server 9000`.
