# Как настроить проверку чеков из почты в MultiTool

Для автоматической проверки подтверждений оплаты подписки MultiTool использует
подключённый Яндекс.Почты. Ниже — настройка и чек-лист.

---

## 1. Подключить Яндекс.Почту в MultiTool

MultiTool работает с Яндекс.Почтой по протоколу **IMAP/SMTP** и требует
**пароль приложения** (не основной пароль от аккаунта).

### Шаги
1. Войти в Яндекс-аккаунт → **Безопасность** → **Пароли приложений**.
2. Создать пароль приложения (тип «Почта»). Скопировать 16-символьный пароль.
3. В приложении MultiTool: **Настройки → Почта (Яндекс)** → указать:
   - адрес: `k.panasyuk@bk.ru`;
   - пароль приложения (скопированный);
   - (серверы: IMAP `imap.yandex.ru:993 SSL`, SMTP `smtp.yandex.ru:465 SSL` — заполнятся сами).

После подключения в чате станут доступны инструменты `yandex_mail_*`.

> Если почта уже подключена — шаг пропускается; проверка запускается командой в чате.

## 2. Чек-лист проверки оплаты (по письму)

Для каждого письма с подтверждением перевода:

- [ ] Письмо найдено в папке «Входящие» (или по поиску: `перевод`, `чек`, `квитанция`, `оплата`, `399`).
- [ ] В письме есть скрин/вложение/номер операции.
- [ ] **Сумма** = 399 ₽ (или кратна 399).
- [ ] **Получатель** — карта/счёт, оканчивающиеся на `…6398` (40817810938046976398).
- [ ] **Дата** платежа — сегодня–2 дня.
- [ ] **Отправитель** (имя/номер) совпадает с тем, кому выдаём ключ.
- [ ] Платёж реальный (не подделан): номер операции в чеке есть.

**Если всё ок** → отправить клиенту **автоответ с ключом** (шаблон №1 из
`docs/ШАБЛОНЫ-ПИСЕМ-по-оплате.md`).

**Если не хватает данных** → запросить доп. подтверждение (шаблон №2).

## 3. Команды в чате MultiTool после подключения

- «Проверь почту на чеки» → поиск писем с оплатами.
- «Посмотри письмо N» → открыть и сверить чек по чек-листу.
- «Отправь ключ клиенту NN» → автоответ с ключом (после подтверждения в чате).

## 4. Безопасность

- Пароль приложения никому не передавать; регистрировать только в настройках MultiTool.
- Ключ доступа `DF7US-RYBAA-C3VP2` выдавать **только после** успешной проверки оплаты.
- Не хранить копии чеков в открытом виде; обработанные письма помечать.

> См. также `docs/ПРОВЕРКА-ОПЛАТ-и-ЧЕКИ.md` — виды принимаемых чеков и критерии валидности.
