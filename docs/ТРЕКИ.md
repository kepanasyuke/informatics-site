# Двухтрековая структура репозитория

Репозиторий `informatika-3-11` построен по двум трекам на каждый класс:
**ИКТ** (информационно-коммуникационные технологии) и **ПРОГ**
(программирование). Каждый трек — 32 урока в год; одна тема занимает 1–N уроков.

> Сверка с ФРП: два трека покрывают все четыре тематических раздела
> Федеральной рабочей программы по информатике (Цифровая грамотность,
> Теоретические основы, Алгоритмы и программирование, Информационные
> технологии). Детали и часы — в [`СВЕРКА-с-ФРП.md`](./СВЕРКА-с-ФРП.md).

## Дерево папок

```
informatika-3-11/
├── СОДЕРЖАНИЕ.md            # годовой план: темы → уроки (ИКТ 32 + ПРОГ 32)
├── docs/ТРЕКИ.md            # этот файл
├── _ШАБЛОНЫ/
│   ├── урок-XX/             # шаблон компоненты (презентация/лекция/приложение)
│   └── тема/                # шаблон темы с несколькими уроками
├── 1-4 класс/
│   ├── 3 класс/
│   │   ├── ИКТ/             # темы трека ИКТ для 3 класса
│   │   └── ПРОГ/            # темы трека программирования для 3 класса
│   └── 4 класс/{ИКТ,ПРОГ}
├── 5-9 класс/
│   ├── 5 класс/{ИКТ,ПРОГ}
│   ├── 6 класс/{ИКТ,ПРОГ}
│   ├── 7 класс/{ИКТ,ПРОГ}
│   ├── 8 класс/{ИКТ,ПРОГ}
│   └── 9 класс/{ИКТ,ПРОГ}
└── 10-11 класс/
    ├── 10 класс/{ИКТ,ПРОГ}
    └── 11 класс/{ИКТ,ПРОГ}
```

## Как ложатся готовые уроки

Готовые уроки помещаются внутрь папки темы соответствующего трека. Пока тема
раскладывается полностью, готовые уроки могут лежать «на месте» в папке темы
(файлы `prezentaciya/lekciya/app` урока), см. карту в `СОДЕРЖАНИЕ.md`.

## Правила именования

- Папка темы: `тема-01-название`.
- Папка урока внутри темы: `урок-01`, `урок-02`, …
- Компоненты урока: `prezentaciya/index.html`, `lekciya/index.html`,
  `app/index.html`.
- Идентификатор урока: `<трек>.<класс>-<тема>.<урок>` (например `ИКТ.7-05.3`).

## Объём

| Трек | Классы | Уроков/год/класс |
|------|--------|:---:|
| ИКТ | 3–11 | 32 |
| ПРОГ | 3–11 | 32 |

Итого по классу — до 64 уроков в год (сетку часов учитель подстраивает под
расписание своей школы).
