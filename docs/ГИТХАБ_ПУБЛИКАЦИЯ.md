# Как опубликовать на GitHub

Репозиторий инициализирован через git (локальная история есть).

## Подключение репозитория

1. Создайте пустой репозиторий на GitHub: https://github.com/new → имя
   `informatika-3-11`. **Не** отмечайте README/.gitignore/license (файлы уже есть).
2. Скопируйте HTTPS-адрес и выполните в папке репозитория:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/informatika-3-11.git
git push -u origin main
```

> До первого push поставьте автора коммита (сейчас коммиты от нейтрального
> `MultiTool <multitool@local>`):
> ```
> git config user.name "Ваше имя"
> git config user.email "ваш@email.ru"
> git commit --amend --reset-author --no-edit
> git push -u origin main
> ```
> `--amend` безопасно использовать только до первого push.

## GitHub Pages (бесплатный хостинг уроков)

- Settings → Pages → Source: `main` / root → Save.
- Уроки станут доступны по адресу
  `https://ВАШ_ЛОГИН.github.io/informatika-3-11/...`, например презентация урока 3 класса:
  `.../1-4 класс/3 класс/урок-01-безопасность-в-интернете/prezentaciya/index.html`.

Презентации и приложения работают в браузере как есть (листание ←/→, печать).
