Базовое понятие

Что такое система счисления

Система счисления — способ записи чисел с помощью цифр. Позиционная: значение цифры зависит от позиции.

Число в системе с основанием p: an...a1a0 = an·pn + ... + a1·p + a0

Основание — количество цифр в системе (десятичная: 10, двоичная: 2...).

Основные системы

  • Двоичная (осн. 2): цифры 0,1
  • Восьмеричная (осн. 8): 0–7
  • Десятичная (осн. 10): 0–9
  • Шестнадцатеричная (осн. 16): 0–9, A=10, B=11, C=12, D=13, E=14, F=15

Перевод из любой системы в десятичную

Перевод в десятичную

10112 = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8+0+2+1 = 11
2F16 = 2·16¹ + 15·16⁰ = 32+15 = 47

Каждую цифру умножаем на основание в степени позиции и складываем.

Перевод из десятичной

Метод деления с остатком

Делим число на основание, пока не станет меньше основания. Остатки, прочитанные снизу вверх, — искомое число.

27 → 27:2=13 ост.1; 13:2=6 ост.1; 6:2=3 ост.0; 3:2=1 ост.1; 1 → читаем: 110112

Универсальный приём для любой системы счисления.

Ключевой приём

Связь двоичной ↔ восьмеричной/16-ричной

8 = 2³, значит каждая восьмеричная цифра = ровно 3 двоичные.

16 = 2⁴, значит каждая 16-ричная цифра = ровно 4 двоичные.

110 1012 → 658 (слева дополните нули: 001 101 01?) — группируем по 3 от конца.

Арифметика в двоичной

Сложение в двоичной системе

0+0=0; 0+1=1; 1+1=10 (перенос 1 в старший разряд); 1+1+1=11
1101 + 1011 = 11000

Правила сложения в двоичной — база для задач на арифметику в ЕГЭ.
