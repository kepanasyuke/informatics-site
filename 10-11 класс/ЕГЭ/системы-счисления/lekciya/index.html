Задачи:

  • освоить переводы двоичная ↔ восьмеричная/шестнадцатеричная через группы;
  • разобрать типовые задачи ЕГЭ на системы счисления.

2. Теория. Позиционные системы счисления

В позиционной системе значение цифры зависит от её позиции (разряда). Число в системе с основанием p, состоящее из цифр an…a0, равно:

Развёрнутая форма: an·pn + … + a1·p1 + a0·p0

Основание p — количество допустимых цифр. В шестнадцатеричной системе цифры обозначают буквами: A=10, B=11, C=12, D=13, E=14, F=15.

3. Переводы

3.1. Из любой системы в десятичную

Раскрываем число по развёрнутой форме и вычисляем.

Пример 1. 10112 = 1·2³+0·2²+1·2¹+1·2⁰ = 8+0+2+1 = 11.
Пример 2. 2F16 = 2·16¹+15·16⁰ = 32+15 = 47.

3.2. Из десятичной в другую систему

Метод последовательного деления на основание: делим число, записываем остаток, пока не получим частное меньше основания. Результат — остатки, прочитанные снизу вверх.

Пример 3. 27 в двоичную: 27→13 ост.1; 13→6 ост.1; 6→3 ост.0; 3→1 ост.1; 1→0 ост.1. Остатки снизу вверх: 110112.

3.3. Двоичная ↔ восьмеричная / шестнадцатеричная

Так как 8=2³ и 16=2⁴, перевод делается группировкой двоичных разрядов (от конца числа):

  • в восьмеричную — по 3 разряда;
  • в шестнадцатеричную — по 4 разряда;
  • недостающие старшие разряды дополняются нулями.
Пример 4. 1101012 → группы по 3: 110 и 101 → 658. По 4: 0011 и 0101 → 3516.

4. Арифметика в двоичной системе

Сложение выполняется поразрядно с переносом в старший разряд, когда сумма разрядов ≥ 2:

  • 0+0=0; 0+1=1; 1+1=10 (перенос); 1+1+1=11.
Пример 5. 11012 + 10112 = 110002.

5. Типовые задачи ЕГЭ

Задача 1. Сколько значащих нулей в двоичной записи числа 40?

Решение: 40 = 1010002. Значащие нули — между/после единиц, кроме ведущих: их три (0·1·0·0·0). Ответ: 3.

Задача 2. Чему равно 1112 + 1118 (ответ в десятичной)?

Решение: 1112=7; 1118=1·64+1·8+1=73. Сумма = 80.

Разберите обе задачи вслух, проверяя каждый шаг с учениками.
